推荐策略 PM 面试 SOP

策略岗不考"你做过什么",考你能不能把一个策略问题讲清楚——定义问题、设计策略、评估效果、复盘迭代。

壹面试考什么 · 四件事闭环

字节三进宫的作者总结:策略岗真正考察的底层能力非常一致——

  1. 问题归因:是供给问题、分发问题、转化问题,还是商业效率问题?
  2. 目标函数与约束:主指标是什么,不能坏的护栏指标是什么?
  3. 策略设计:能提出可执行的抓手,而不是只停留在方向判断。
  4. 结果解释:把数据变化和策略动作之间的因果链路讲明白。

一句话:「定义问题 → 设计策略 → 评估效果 → 复盘迭代」的完整闭环能力。

能拿高分的,从来不是经历最丰富的人,而是最能把复杂问题讲清楚、讲透的人。 —— 《字节三进宫｜附搜推广策略pm高频面经》
贰简历与项目 · 从"做了什么"到"为什么这么做"

项目七维自查

每个项目都要能讲清:背景 / 目标 / 行动 / 结果(核心指标+护栏指标)/ 难点 / 复盘 / 下一步迭代。 一面 80% 时间在深扒简历,每个数字都会被追问口径。

项目介绍五步结构

  1. 先讲背景和业务目标;
  2. 问题发现与定义(可从用户视角举例);
  3. 影响因子拆解(按链路或人群);
  4. 做了哪些动作、结果是什么、如何验证;
  5. 结论 + 下一步优化。

一面前的 checklist(北大作者):能否结构化连贯表述每段项目故事线 / 说清简历上每个指标数据 / 讲清自己在团队中的角色 / 有失败项目的复盘思考 / 准备了反问环节。做过 ≠ 理解,能讲 ≠ 能讲明白。

叁高频题型 · 概念与业务

链路题:召回 → 粗排 → 精排 → 重排

  • 多路召回:实时行为、搜索意图、相似商品、协同过滤、长期兴趣、购物阶段、互补关联、热门/新品/促销。
  • 准入过滤:库存、配送、风控、重复曝光、质量——任一不满足即出局。
  • 重排解决三件事:用户体验(打散、多样性)、算法效率(多任务融合、上下文感知、实时性)、流量调控。
  • 策略 PM 不负责模型,但负责设计整套决策机制:圈人群(新老/意图清晰度/复购/价格敏感)+ 识别信号时效(10 分钟点击=强信号,半年前点击=弱信号)。

内容推荐策略题

  • 指标增长向:扩召回(数据稀疏场景尤其有效)、调权重(提渗透调 CTR 导向,提种草调 CVR 导向)、引入短期搜索信号。
  • 体验优化向:多样性打散(封面/作者/类型/POI)、优质与低质内容提降权(柔性优于强插)。

经典难题:CTR 上升,时长却下降?

CTR = F(质量, 兴趣, 场景),优化 CTR 可能只捕捉了瞬时兴趣或高点击封面,但内容留不住人。 要拆「兴趣匹配前提下的内容时长承载能力」,并建立更全面的评估:深度消费率、兴趣浓度、时长分布; 用因果推断研究「曝光→点击→深度互动→次日留存」的传导链。短期兴趣决定 DAU,长期兴趣决定 MAU。

供给 vs 分发

按产品生命周期定优先级:冷启动优先扩供给(分发只做基础保障);增长期双线并行、分发权重抬高; 成熟期重点优化优质分发,供给转向结构提质。供给是内容底盘,分发是增长杠杆。

天花板分析

面试常问「这个项目理想态是什么、值多大」:用理想化实验、更细的数据分析、组织业务重心来判断; 能达到理论值 70-80% 就很好;注意边际递减(前 20% 优化带来 80% 收益);组合拳优于单点突破。

肆产品 sense · 开放题怎么答
  • 矛盾-假设-验证-迭代重构每段经历:被问「资源减半如何剪枝」,从指标贡献度拆,而不是当场卡壳。
  • 可量化假设:「用户决策成本高,假设信息不一致导致犹豫,做 A 动作,用转化率验证,后续分人群承接」。
  • 补数据底气:SQL + AB 基础(显著性、混杂因子),主动说「按分层看异质性」立刻拉开差距。
  • 日常拆策略:看到会员红包想「发放对象、券面额、目的」,把刷 App 变成训练。
  • 概念题回答三步:跳出定义复读做通俗类比 → 依据根因多维拆解 → 总结底层逻辑 + 应用经验。
伍面试流程 · 各轮重点与反问
  • 一面(深扒简历):项目真实性、指标口径、实验与护栏指标;策略产品特质;失败复盘是否具体。
  • 二面(业务拆解):从机制/公式出发拆业务;机制→中间指标→消耗/ROI 的映射;产品抽象(输入、规则、输出、兜底)。
  • 三面(行业与反事实):广告底层机制、行业差异、反事实推演;扛住压力面。
  • HR 面:匹配度为主;稳定性、价值观、职业规划、入职时间。
  • 反问环节:业务分工/岗位内容/没答好的 case 题/人才画像;若发现画像与表现有出入,可「理解您的 concern + 补充对应经历」挽回。
  • 自我介绍两种思路:实习经历简述,或「3 个岗位特质 + 对应经历」,收尾表达加入意愿。

各厂风格(社招作者体感):简历通过率取决于方向垂直度;面试流程基本是「自我介绍 → 看机会原因 → 讲项目(追问)→ 业务开放题 → 反问」,差异主要在追问深度与开放题风格。

陆挂科复盘 · 为什么策略岗总挂

一位面试者的真实复盘:自认为案例讲得清晰,却被面试官一句「你做的都是执行动作诶」击穿。三条根因——

  1. 把数据当任务,而不是信号:看到「点击率低」就直接想怎么解决,缺少「审视问题本身」这一步(它可能只是新渠道流量质量差的表征)。
  2. 停留在分类统计,而非因果归因:按用户/流量/时间拆解只是找到问题发生的位置,还要推断因果链(如「新用户点击低,是因为推荐算法与他们的价格偏好不匹配」)。
  3. 追求单点优化,忽视全局设计:调用现成工具优化单一指标,缺少对副作用与多目标权衡的「决策系统」视野。

其他高频挂因:准备不系统(只复盘自己的项目,对目标业务的核心矛盾、典型题型、行业语言准备不足); 停在动作层(被追问为什么选这个抓手、为什么看这个指标、放量后有什么副作用就露怯); 经历越匹配预期越高(面试官默认你懂业务逻辑与指标体系)。

柒30 天准备清单
  1. 第 1 周 · 项目重构:每段经历按七维重写;用「矛盾-假设-验证-迭代」重述;每个数字备好口径。
  2. 第 2 周 · 链路与题型:吃透召回-粗排-精排-重排;整理扩召回/调权重/打散/提降权;准备 CTR↑时长↓、供给 vs 分发、广告 vs 推荐三道大题。
  3. 第 3 周 · 业务与指标:选定 2-3 家目标公司,研究其核心矛盾与指标体系;补 SQL 与 AB 基础(显著性、混杂因子、分流节点)。
  4. 第 4 周 · 模拟与反问:找人 mock,强制用总分总结构;准备 4 个反问;演练压力面(模糊问题先讲思路框架再落细节)。

[红书R]对于闭环电商平台，广告策略和自然推荐策略是两套完全不同的系统，但又在同一个流量池里竞争。理解它们的区别，是做好策略产品经理的基本功。 一、核心目标不同：钱 vs 人 [清单R]闭环广告策略 核心目标：平台广告收入最大化 - 短期：最大化 eCPM（预估点击率 × 出价） - 中期：平衡广告主 ROI，让他们愿意持续投钱 - 长期：建立健康的广告生态，让更多商家愿意付费买量 广告系统的第一优先级是把流量卖给愿意出更高价的人。出价高、点击率高的广告，就应该排前面。 [清单R]自然电商推荐策略 核心目标：用户体验和平台 GMV 最大化 - 短期：最大化用户点击率、转化率、停留时长 - 中期：提升用户复购率、LTV（生命周期价值） - 长期：建立用户「在这里买东西」的心智 自然推荐的第一优先级是给用户看他最可能买的东西。用户喜欢什么，就推什么。 二、机制设计不同：拍卖 vs 预估 1. 排序机制 [种草R]广告排序公式： 排序分数 = pCTR ✖️ bid ✖️ 质量分 - pCTR：预估点击率（模型预测） - bid：广告主出价（直接输入） - 质量分：广告素材质量、落地页体验等（防止劣质广告） [向右R]关键：bid 是核心变量，广告主可以用钱换位置。 [种草R]自然推荐排序公式： 排序分数 = f(用户特征, 商品特征, 上下文) + 业务规则 - 模型预测的是用户对这个商品的偏好程度 - 没有「出价」这个变量 - 业务规则可能是：新品扶持、品类打散、去重等 [向右R]关键：商家无法直接花钱买位置，靠兴趣预估匹配。 2. 流量分配机制 [清单R]广告： - 竞价机制：价高者得 - 预算控制：广告主设置日预算，花完下线 - 定向投放：广告主可以圈定人群（年龄、性别、兴趣等） [清单R]自然推荐： - 个性化机制：根据用户历史行为推荐 - 探索与利用：留一部分流量测试新商品 - 生态调控：强制打散、扶持新品、控制头部垄断 3. 冷启动机制 [清单R]广告： - 新广告主/新广告计划，系统会给一定的冷启动流量测试效果 - 广告主可以通过提高出价来加速冷启动 [清单R]自然推荐： - 新商品依赖冷启池流量获得初始曝光 #产品经理[话题]# #产品经理面试[话题]# #互联网大厂[话题]# #推荐系统[话题]# #推荐策略[话题]# #策略产品[话题]# #面经[话题]# #暑期[话题]# #大厂暑期实习[话题]# #大厂面经[话题]#
