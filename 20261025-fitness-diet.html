健身饮食吃法 SOP

不用称重算卡路里:一手测量、一个锚点、一个时间差——吃对了,练才有意义。

小红书搜索「健身饮食推荐」,爬取 15 篇帖子(全部通过完整性校验)。这个话题的共识非常集中: 减脂靠「结构」不靠「饿」,增肌靠「固定」不靠「猛吃」,而训练前后的碳水时间差决定你练得值不值。 以下按「公式 → 减脂 → 增肌 → 时间差 → 新手原则 → 穷鬼实操 → 避坑」整理。

壹一个公式 · 手测量法

榜首帖(7476 赞)的核心贡献:不用苦算卡路里,用拳头、手掌、捧来量——

餐次碳水蛋白蔬菜
早餐1 拳1 掌1 捧
午餐1 拳1 掌2 捧
加餐低糖水果少量 + 坚果一小把
晚餐半拳1 掌2 捧

配一张隐形热量避雷表:高卡酱料、伪健康加工品一眼分清。减脂不用饿肚子,选对食材吃饱也能稳步掉秤。

贰减脂 · 锚点法(只动一个变量)

最硬核的一篇(85kg→68kg 亲测)提出「建立锚点、控制变量」:很多人什么都想动, 最后身体不知道应该干嘛,代谢直接躺平。

  1. 锁死锚点:蛋白质 1.6g/kg、脂肪 0.9g/kg 固定不动——蛋白质是肌肉的保护伞,脂肪是激素的原材料。
  2. 唯一变量:碳水,从 3.0g/kg 起阶梯下调,每降 3-4kg 砍一档:3.0 → 2.5 → 2.0 → 1.5 g/kg。
  3. 全程只改主食克数,其他食物种类、重量、烹饪方式原封不动——身体永远只面对一个变量,适应就降,不适应就停。
  4. 平台期主动拉高碳水恢复代谢;热量缺口约 300-500 kcal。

评论区提醒:算碳水要把所有食物的碳水都算进去(蔬菜、奶、坚果都有),别只算主食。

叁增肌 · 三餐模板 + 调整规则
  • 早餐:燕麦/全麦面包等主食 + 鸡蛋 + 牛奶或酸奶
  • 午餐:鸡胸肉/牛肉/鱼虾 + 米饭或面食 + 蔬菜
  • 晚餐:优质蛋白 + 适量主食 + 蔬菜;训练量大时增加米饭、土豆、紫薯

调整规则:体重长期不涨 → 加主食;体重涨太快、腰围明显增加 → 减主食和高油食物; 每周固定时间记录体重和腰围。食材可自由替换(鸡胸换牛肉/鱼/虾,米饭换面条/玉米/土豆/紫薯),上班族可提前备餐分装。 增肌不是吃得越多越好,也不是每天只吃鸡胸肉。

肆时间差 · 训练前后碳水
  • 训练前吃慢碳,给身体储备能量,训练更有劲。
  • 训练后 30 分钟内补快碳,快速恢复糖原、保住肌肉——不补容易肌肉流失、代谢下降、减脂卡平台。
  • 记住:练后吃干净快碳,控制好量,才会越练越瘦。
  • 晚上练完不用怕吃:时间本身不会让你长胖,全天总热量才更重要。
伍新手五原则
  1. 不要戒主食:训练需要糖原,米饭、面、燕麦、红薯、玉米都能吃;真正该减的是奶茶、甜饮料、炸物、薯片、蛋糕和随手零食。
  2. 每顿先保证蛋白质:至少一块手掌大小的肉/鱼/虾,或鸡蛋+豆制品;鸡胸肉不是唯一选择,轮换才不会一周吃崩。
  3. 蔬菜大胆吃:午晚各 250-300g,上海青、生菜、娃娃菜、菠菜、番茄、黄瓜、菌菇、冬瓜轮换。
  4. 油要控制但不戒:烹调油每天 20-25g 以内;隐形热量在炒菜油、酱料、坚果、沙拉酱。
  5. 前两周别称重:先固定食物结构;连续 2-3 周体重腰围不降,再减半碗饭或 100-150 kcal。
陆穷鬼 / 打工人实操
  • 沙县减脂法(423 赞/238 评):米饭吃不完、菜吃完、肉不吃皮、鸡蛋 1-2 个就够——9.9 元鸭腿饭也能吃出结构。
  • 食堂版:早餐两蛋+无糖豆浆;午餐一拳米饭+卤鸡腿(少油)+多份青菜;晚餐玉米/红薯+同样的肉菜。
  • 7 天抗炎食谱:大原则就一条——优质碳水 + 优质蛋白 + 膳食纤维;用橄榄油替代食用油,多吃深色蔬菜;午晚餐按「一拳蛋白+一拳蔬菜+半拳主食」。
  • 官方参考:卫健委《成人肥胖食养指南 2024》——不挨饿、不断碳、不吃水煮菜;每月 2-4kg,看 7 天平均体重+腰围,别纠结单日波动;BMI 正常不建议盲目减重。
柒避坑清单
  1. 伪健康食品:高卡酱料、沙拉酱、坚果(一小把就好)、果汁饮料——「看起来没多少」的热量才是减脂杀手。
  2. 碳水认知:莲藕、胡萝卜、芋头、栗子、玉米都算碳水;糯玉米不算优质碳水,选水果玉米。
  3. 只看单日数字:喝水、盐分、经期、排便都会让体重波动,看 7 天平均值 + 腰围。
  4. 练完断碳:越练越难瘦的常见原因——糖原没补,身体分解肌肉供能。
  5. 照搬别人的食谱:孕期/哺乳期/未成年、糖尿病、肾病、肠胃病人群请咨询医生;食谱只解决「怎么吃」,体质、情绪、作息、执行不同步调整,停了还会胖回去。
